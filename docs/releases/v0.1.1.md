# AppLens 0.1.1 · 软件透视

整理仓库目录，安装和启动入口集中到 `install/`，辅助配置集中到 `config/`，
使用文档和许可材料分类收纳。公开提交说明统一使用 AppLens。

## Windows 安装

需要 Windows 10/11 x64、NTFS 和 Node.js 24.18.0（含 npm）。

```powershell
git clone --branch v0.1.1 https://github.com/JichaoChen1123/app-lens.git
cd app-lens
powershell -NoProfile -ExecutionPolicy Bypass -File .\install\install.ps1
.\install\applens.cmd --help
```

安装脚本下载本页的 Windows 原生组件，验证版本、架构和 SHA-256，安装锁定依赖并构建。
完整 `.tgz` 安装包已经包含编译产物和 Windows 原生组件，也可隔离安装：

```powershell
npm install --prefix .\applens-local --ignore-scripts --registry=https://registry.npmjs.org .\jichaochen1123-app-lens-0.1.1.tgz
.\applens-local\node_modules\.bin\applens.cmd --help
```

0.1.0 用户可继续使用原安装包，新版源码请按上述新路径启动。
本版本未发布到 npm registry，请使用 GitHub 附件。
