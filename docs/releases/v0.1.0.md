# AppLens 0.1.0 · 软件透视

让软件内部看得见。本地软件分析命令行工具与 MCP 服务。

本版本完成 Windows x64 原生组件发布、带校验的 PowerShell 安装、中文与空格路径
端到端验收，并修复 scoped npm 包安装识别。产品界面与使用文档统一为 AppLens。

## Windows 安装

需要 Windows 10/11 x64、NTFS 和 Node.js 24.18.0（含 npm）。

推荐克隆本版本源码，运行根目录安装脚本：

```powershell
git clone --branch v0.1.0 https://github.com/JichaoChen1123/app-lens.git
cd app-lens
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
.\launchers\applens.cmd --help
```

安装脚本自动下载下方 `applens-windows-x64-native.zip`，检查版本、SHA-256 和架构，
安装锁定依赖并构建。无需安装 C++ 编译器。不会自动修改 MCP 客户端配置。

也可以下载下方 `.tgz` 完整包，保存到当前目录后隔离安装：

```powershell
npm install --prefix .\applens-local --ignore-scripts --registry=https://registry.npmjs.org .\jichaochen1123-app-lens-0.1.0.tgz
.\applens-local\node_modules\.bin\applens.cmd --help
```

完整包已包含编译产物和 Windows 原生组件，无需再次运行源码安装脚本。
本版本未发布到 npm registry，请使用本页附件。
